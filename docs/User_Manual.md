# User Manual

## 1. Accessing the System
- Open the frontend URL in your browser.
- Enter your email and password to log in.

## 2. Employee Actions
### Submit Salary Advance Request
1. Log in as Employee.
2. Go to the dashboard request form.
3. Enter amount and reason.
4. Click Submit.

### View Request History
- In dashboard, check My Requests list for current statuses.

## 3. Manager/Admin Actions
### Review Pending Requests
1. Log in as Manager/Admin.
2. Go to Pending Requests section.
3. Select Approve or Reject.
4. Optionally provide comment.

## 4. Validation and Errors
- Invalid forms show inline error messages.
- Business rule violations (such as amount > 50% salary) show clear API error messages.

## 5. Security Notes
- Do not share credentials.
- Log out after use on shared devices.

## 6. Troubleshooting
- If login fails, confirm credentials.
- If API is unavailable, check backend and database container status.
